# SS Logistics Operating System

Web app for SS Logistics, built module by module.

- **Live app:** https://rajputrohit01.github.io/ssl-os/
- **Module 1 — Warehouse Management (v1.1):** rake receipt at sidings, godown GRN, loading slips, Paltai, challans, Adjustment Dispatch, returns, damage, monthly stock count, SAP billing tagging, labor billing.
- **Backend:** Supabase (database rules, permissions and tests live in the Supabase project).
- **Access:** sign in, then an admin activates you and assigns permissions and locations on the Users screen.
